# YOLO 螢幕截圖裁剪工具

用於 YOLO 目標檢測模型訓練的圖片裁剪工具。

## 功能特色

- **多種圖片載入方式**
  - 透過檔案對話框開啟圖片
  - 從剪貼簿貼上圖片 (Ctrl+V)
  - 拖放圖片檔案到應用程式
  - 支援從剪貼簿貼上圖片路徑

- **可調整裁剪框**
  - 預設裁剪尺寸 640x640
  - 可自由移動裁剪框位置
  - 可透過四角調整裁剪框大小
  - 可透過參數輸入框精確設定尺寸

- **便捷操作**
  - 點擊空白處可取消輸入欄位聚焦
  - 圖片保存到指定目錄
  - 支援 Enter 鍵快速保存

## 安裝需求

- Python 3.8+
- Pillow (影像處理庫)

## 安裝步驟

1. 安裝 Python依賴:
```bash
pip install -r requirements.txt
```

2. 執行應用程式:
```bash
python main.py
```

## 使用說明

1. **載入圖片**
   - 點擊「📂 開啟檔案」按鈕選擇圖片
   - 或使用 Ctrl+V 從剪貼簿貼上圖片
   - 或將圖片檔案拖放到應用程式視窗

2. **調整裁剪框**
   - 拖曳裁剪框內部移動位置
   - 拖曳裁剪框四角調整大小
   - 在上方輸入框中輸入寬度和高度

3. **設定輸出路徑**
   - 點擊「瀏覽」按鈕選擇輸出資料夾

4. **保存裁剪**
   - 點擊「💾 保存裁剪」按鈕
   - 或按 Enter 鍵保存

## 支援的圖片格式

- PNG
- JPEG/JPG
- BMP
- GIF
- WebP

## 快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| Ctrl+V | 從剪貼簿貼上圖片 |
| Enter | 保存裁剪結果 |
| ← | 上一張圖片（資料夾模式） |
| → | 下一張圖片（資料夾模式） |
| Ctrl+O | 開啟資料夾 |
