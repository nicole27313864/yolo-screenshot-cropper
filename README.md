# YOLO 螢幕截圖裁剪工具

用於 YOLO 目標檢測模型訓練的圖片裁剪工具，同時支援圖片和影片處理。

## 功能特色

### 圖片處理
- **多種圖片載入方式**
  - 透過檔案對話框開啟圖片
  - 從剪貼簿貼上圖片 (Ctrl+V)
  - 拖放圖片檔案到應用程式
  - 支援從剪貼簿貼上圖片路徑
  - 開啟資料夾瀏覽多張圖片

- **可調整裁剪框**
  - 預設裁剪尺寸 640x640
  - 可自由移動裁剪框位置
  - 可透過四角調整裁剪框大小
  - 可透過參數輸入框精確設定尺寸
  - 即時顯示裁剪尺寸

- **裁剪模式**
  - 自動命名：自動依序編號
  - 手動命名：自訂輸出檔名

### 影片處理
- **支援多種影片格式** (MP4, AVI, MKV, MOV, WebM)
- **VLC 硬體加速播放** - 流暢播放大影片
- **幀導航**
  - 上一幀 / 下一幀
  - 播放 / 暫停
  - 時間軸拖動跳轉
- **從影片擷取幀** - 可裁剪後保存為圖片

## 安裝需求

- Python 3.8+
- Pillow (影像處理庫)
- OpenCV (影片處理)
- VLC (影片播放)

## 安裝步驟

1. 安裝 Python 依賴:
```bash
pip install -r requirements.txt
```

2. 確保系統已安裝 VLC 媒體播放器 (用於影片播放功能)

3. 執行應用程式:
```bash
python main.py
```

## 使用說明

### 圖片模式

1. **載入圖片**
   - 點擊「📂 開啟檔案」按鈕選擇圖片
   - 或使用 Ctrl+V 從剪貼簿貼上圖片
   - 或將圖片檔案拖放到應用程式視窗
   - 或使用 Ctrl+O 開啟資料夾

2. **調整裁剪框**
   - 拖曳裁剪框內部移動位置
   - 拖曳裁剪框四角調整大小
   - 在上方輸入框中輸入寬度和高度

3. **設定輸出路徑**
   - 點擊「瀏覽」按鈕選擇輸出資料夾

4. **保存裁剪**
   - 點擊「💾 保存裁剪」按鈕
   - 或按 Enter 鍵保存
   - 或按 Ctrl+S 保存裁剪（可覆蓋）
   - 或按 Ctrl+Shift+S 保存為新檔案

### 影片模式

1. **開啟影片**
   - 點擊「📹 開啟影片」按鈕選擇影片檔案

2. **播放控制**
   - 使用播放/暫停按鈕或空白鍵控制播放
   - 拖動時間軸跳轉到指定位置
   - 使用左右方向鍵切換幀

3. **調整裁剪框**
   - 與圖片模式相同

4. **保存影片幀**
   - 按 Ctrl+S 保存當前影片幀（完整尺寸，每次都是新檔案）
   - 檔案會自動命名為 `[影片名]_frame_XXXX.png`

### 影片格式

- WebM

## 快捷鍵

| 快捷鍵 | 功能 | 適用模式 |
|--------|------|----------|
| Ctrl+V | 從剪貼簿貼上圖片 | 圖片 |
| Ctrl+S | 保存裁剪 / 保存影片幀 | 圖片+影片 |
| Ctrl+Shift+S | 保存裁剪為新檔案 | 圖片 |
| Enter | 保存裁剪結果 | 圖片 |
| ← | 上一張圖片 / 上一幀 | 圖片+影片 |
| → | 下一張圖片 / 下一幀 | 圖片+影片 |
| 空格 | 播放/暫停影片 | 影片 |
| Ctrl+O | 開啟資料夾 | 圖片 |

## 設定選項

- **自動命名**: 自動依序編號產生檔名
- **詢問覆蓋**: 檔案存在時詢問是否覆蓋
- **影片硬體加速**: 啟用顯示卡解碼提升大影片播放效能
- **通知聲音**: 操作成功/失敗時播放提示音
